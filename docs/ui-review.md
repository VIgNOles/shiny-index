# 公開UIの次回レビュー項目

作成日: 2026-10-07。更新日: 2026-10-08。実装済みと未検証を区別する。

## 現在確認できていること

検索、P/Sを含む絞り込み、日付条件、並べ替え、結果CSV、全件データ取得を実装済み。P/Sとレアリティを先頭に置き、全8条件をキー操作不要のチェックボックスに変更した。詳細条件は折りたたみ、選択中の条件を表示する。収録範囲は件数、P/S内訳、期間、欠損、未確認範囲を見出し付きで表示する。Edge/PlaywrightでPC幅と390px幅の選択、並べ替え、リセット、URL反映、横切れなしを検証した。実スマートフォン端末での操作感は未確認。公開カード版は1,466件。

## 次のUI作業（優先順）

1. 実スマートフォン端末で検索・複数絞り込み・並べ替え・リセット・追加表示を確認する。ブラウザ幅390pxの自動試験は実機確認の代わりにしない。
2. キーボードで詳細条件の開閉を確認済み。チェックボックスのアクセシブル名と0件案内も自動確認済み。スクリーンリーダーでの通知と実端末のフォーカス操作は未確認。
3. カードの出典表示は、Wiki個別ページと収録元一覧の別リンク、確認状態の文言を分けて実装した。個別ページ未確認の47件には架空のリンクを作らず、一覧に収録したことを明示する。実端末でリンクの押しやすさを確認する。

## 変更時の受け入れ確認

- PCと幅390pxのブラウザ、および実スマートフォン端末で検索・複数絞り込み・並べ替え・リセット・追加表示を操作する。
- キーボード操作、フォーカス表示、ラベル、0件時の案内、横スクロールの有無を確認する。
- 版・更新日時・出典・データ取得リンクが読め、変更後も匿名公開URLの配布データと版が一致する。
- UI変更は公開データの採用と分離し、検証済みsiteを公開した後に表示を確認する。
