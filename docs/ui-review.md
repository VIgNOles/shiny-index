# 公開UIの次回レビュー項目

作成日: 2026-10-07。これは改善案と確認項目であり、実装・実機検証の完了記録ではない。

## 現在確認できていること

検索、P/Sを含む絞り込み、日付条件、並べ替え、結果CSV、全件データ取得を実装済み。PCとブラウザ幅390pxで基本操作と横切れなしを確認した。実スマートフォン端末での操作感は未確認。公開カード版は1,466件。

## 次のUI作業（優先順）

1. スマホの絞り込みを実機で確認する。現在は8種類の複数選択欄が2列で並ぶ。P/S・レアリティなど頻用条件を先に見せ、残りを詳細条件として整理する案を検討する。複数選択に特別なキー操作が要らず、選択中の条件と解除方法が分かることを確認する。
2. 収録範囲の表示を読みやすくする。現在の長い注意文とJSON表示から、収録件数・対象期間・欠損・未確認範囲を見出し付きの短い要約で読めるようにする案を検討する。公式の全網羅を示す表現にしない。
3. カードの出典表示を確認する。各カードでWiki個別ページ、一覧などの収録元、確認状態を区別して読めること。個別ページ未作成の47件には架空のリンクを作らず、未掲載を明示する。

## 変更時の受け入れ確認

- PCと幅390pxのブラウザ、および実スマートフォン端末で検索・複数絞り込み・並べ替え・リセット・追加表示を操作する。
- キーボード操作、フォーカス表示、ラベル、0件時の案内、横スクロールの有無を確認する。
- 版・更新日時・出典・データ取得リンクが読め、変更後も匿名公開URLの配布データと版が一致する。
- UI変更は公開データの採用と分離し、検証済みsiteを公開した後に表示を確認する。
