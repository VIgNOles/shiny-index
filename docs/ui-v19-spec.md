# UI v19：消去付きアピール

全1,419カード/24,025項目を保存済み原本r20から再変換する。対象は28枚のPカード、108スキル項目（パネル23・思い出85）、消去記載114フィールド、171アピール。Sカードを含む既存項目・coverage・固定ID・8手修正を保持する。原本への書込み、Wikiへの通信は不要。表示と検索操作を追加するためUI v19。データのみ更新する場合はUI番号を変えない。

## 根拠と構造

保存R01「スキル効果の解説」appeal_008（SHA31fc776620cf8afe25d60f2acc634d2bcdf9721972c4b7143054f026deedb913）と28カード原HTMLの原セルを照合する。アピールに隣接する最初の完全な「消去」括弧のみを取り込む。未知の名前や不完全な指定、条件括弧の中、離れた消去指定は推測しない。

既存metric=appealを保持し、optional status_consumptionへ対象とUP/DOWN、timing=after_appeal、quantity=all、scaling=status_count、passive_included=falseを追加する。アピール属性と消すステータスの属性は別の情報。Vo/Da/Viと「Da & ViUP」の共有末尾を正規化し、個別UP/DOWN・複数対象・本体/Link/思い出Linkごとの対応関係と順序を保持する。

保存R01に従い、指定ステータスの合計数で倍率が増え、そのアピール部分の直後に残りターン数に関係なく全て消去する。ライブスキル全体の終了後としない。パッシブスキルは個数にも消去にも含めない。複数指定を両方必須の発動条件としない。4個以上で最大倍率という一般説明から原文にない最小倍率・個別計算値は生成しない。実セルに0.5～2倍などの記載もあるため、数式を使った補正や上書きは行わず原文の値を残す。最大のみの記載から下限を補わない。

## 表示・検索

効果の種類「消去付きアピール」を追加する。既存「ライブ・思い出のアピール」でも引き続き検索できる。これは新しい独立効果ではなく、消去指定を持つ同じアピールへの絞り込み。効果の対象はアピール属性を意味し、消す属性は「DanceUP」「DanceDOWN」などのキーワードで探す。画面ヘルプへ区別を記載する。

一致する1つのアピール内だけで属性・消去対象・キーワードを判定し、別アピールや隣の付与効果から借用しない。消去を継続ターンとして扱わない。表示は対象ステータス、消去タイミング、全消去、個数による倍率変化、パッシブ対象外を明記する。追加条件が未構造化である注意は保持する。
