# UI v17：特殊ライブ効果の検索と期間の区別

取得済み原本r19の派生変換で、リザレクション、観客ステータス解除、デュエット/当ターンへのデュエット追加、Growの最小興味、魅了、熱狂を型にする。取得列・固定ID・6手修正・基礎カード・旧不変バンドルは変更しない。

## 根拠と境界
保存R01「スキル効果の解説」のリザレクション効果付与、ステータス効果解除、デュエット追加、デュエット、魅了、熱狂の説明と、各カードの原表を参照する。R01 SHA31fc776620cf8afe25d60f2acc634d2bcdf9721972c4b7143054f026deedb913。新Wiki取得なし。

- リザレクションは即時回復とは別型。割合・付与期間・使用可能回数と、メンタル0時の回復を保持する。
- 観客ステータス解除は全観客が対象で、興味変動無効を除外する。アビリティ解除とは表示しない。クイックのコストは期間に転用しない。
- デュエットは単位ごとに独立した1効果として保持する。同じ対象の2回呼出を重複除去しない。対象は編成/ユニット/指定アイドルを区別し、原文で確認できたユニット略記だけを正式名へ変換する。参加していない対象や使用者本人を選べるとは表示しない。
- デュエット追加は当ターンのアピールへの追加であり、持続1ターンのバフとは扱わない。
- Grow最小興味は固定倍率やアピール倍率範囲と別型。魅了と熱狂は別効果。説明資料にある固定の20/25%をカード原表にない数値として追加しない。
- 全観客の明記はその効果だけに付け、隣の裸のステータスへ無条件に伝播しない。
- 期間幅2～4はturn_range、最大3ターンだけの記載はturns_maximum。確定のturns値に変換しない。継続ターンの絞込みは期間幅の下限で判定し、最大値だけの期間は最低継続の保証がないため対象外。画面でその基準を説明する。
- 既存の機能区間・発動/Grow条件を新効果にも付ける。数値効果のなかったGrow2区間は新たな効果へ条件が結合し、条件だけの独立記録は不要になる。

## 配布と互換
detail_schema1.0のeffect_detailsへ7種のallowlisted metricと限定フィールドを追加する。原文の全文や不明な名前を公開へ流さず、型・対象名・期間・論理式を検証する。旧UI v16は新しい種類の日本語表示/選択肢や期間幅の検索に未対応だが、既存の基本/詳細検索を維持する。完全に旧画面へ戻す場合は検証済みUI16タグと元の不変データも保持する。UI16＋新データの切戻しも別途操作確認する。

画面の効果選択肢・表示・期間検索を変えるためUI v17。純粋なデータ追加ではUI番号を上げない。

## 対応規模
UI16最終版に対し208項目/244効果を追加。リザレクション29、観客ステータス解除2、通常デュエット172、当ターン追加1、最小興味3、魅了23、熱狂14。

認識済み効果に付く区間条件は664構造化/未対応0。旧UI用fallback57は意図的に維持する。全発動制限の分母ではない。
