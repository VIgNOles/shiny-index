## 収録項目と境界

既存の固定 card_id で結び、card_kind でP/Sを分ける。カード名を結合キーにしない。

| 種別 | 項目 | Wiki節と扱い |
|---|---|---|
| P | パネルのライブスキル・パッシブスキル | スキルパネルの各ノードを独立記録。名称、効果、SP、解放条件、位置を持つ |
| P | MBライブスキル | スキルパネル内のMB小表。通常版と別記録にし、MB段階（例: 2/5）と対応する通常版を関連付ける。対応不明なら要確認 |
| P | 固有アビリティ | スキルパネル／アビリティ節。重複掲載は1件とし、両方の出典位置を保持 |
| P | 上限値 | パネルの上限UPノードごとに対象ステータス、増分、SP、解放条件を保持 |
| P | 思い出アピール | Lvごとに記録。Link等に加え、表にある場合はチャージアピールを任意の子項目として保持。ライブスキル検索タグには混ぜない |
| S | アイデア・ひらめき・楽曲熟練度 | 基本情報。熟練度は複数値を許し、暫定値・空欄・未確認を区別 |
| S | 最大Lvステータス | ステータス表の最高Lv行のLv・特訓段階・Vo/Da/Vi/Me。Lv80固定にしない |
| S | パネルのライブ・パッシブ・上限値 | Pと同様。S固有のイベント解放条件も保持 |
| S | クイックスキル | S-URのパネルで確認。ライブ／パッシブと別種にし、気力コストを保持。ファイトスキルとは区別 |
| S | 所持ライブスキル | 所持スキル節。origin=possessed としてパネル版と区別し、取得Lvを保持 |
| S | サポートスキル | 所持スキル節。名称・効果・複数の取得Lv／スキルLv対応を保持 |

Pのステージスキル・適正、Sのファイトスキルは今回は収集しない。not_collected と記録し、「該当なし」と同一視しない。283ステージの性能を収録済みとは表示しない。

## 原本と版管理の案

現行の9タブと cards.json schema 1.0 は変更しない。実装時は原本のコピーで詳細用タブの導入、読戻し、既存9タブの差分0を確認してから原本を切り替える。

| 追加タブ案 | 1行の意味 | 主なキー・内容 |
|---|---|---|
| 詳細カード | カード単位の詳細状態とS固有値 | card_id一意、card_kind、Wiki URL、アイデア、ひらめき、最大LvとVo/Da/Vi/Me、確認日時 |
| 詳細項目 | パネルノード、MB、思い出Lv、所持スキルの1件 | 固定detail_id、card_id、種別、節、順序、名称、SP、解放条件、MB段階、通常版への参照、構造化効果、手修正 |
| 詳細属性 | 複数値・段階値の1件 | 親ID、属性種別、順序、Lv、値、暫定フラグ。熟練度、サポートスキルのLv対応、Grow段階に使用 |
| 詳細出典 | 項目・属性ごとの根拠 | 対象IDとフィールド、個別Wiki URL、節・表・行、取得日時、応答ハッシュ、確認状態 |
| 詳細収録範囲 | カード×節の処理状態 | card_id、節、状態、理由 |

詳細項目の種別は panel_live / mb_live / panel_passive / quick_skill / unique_ability / cap_increase / memory_appeal / possessed_live / support_skill。節は skill_panel / memory_boost / memory_appeal / possessed_skills。P/S別に許容組合せを検証する。detail_id は初回採用時に台帳へ固定し、Wikiの行順・表記変更で再生成しない。取得候補と手修正を分け、既存の手修正優先・別名統合・差分レビューを詳細にも適用する。位置・名前だけで同一性を断定せず、疑義があればレビューへ送る。

収録状態は not_collected / missing_page / missing_section / extracted / reviewed / no_entry_confirmed / needs_review とする。空配列は reviewed または no_entry_confirmed のときだけ「該当なし」を意味する。

公開時は基本索引と独立した版付き詳細バンドルにし、detail_schema_version、detail_dataset_version、対応する base_dataset_version、更新日時、件数、節別の収録範囲、内容ハッシュをmanifestへ記録する。Webは互換のある基本版・詳細版の組だけを読み、詳細未登録カードは基本索引として表示する。JSONを正本とし、配布形式追加は既存のCSV非公開範囲が確定してから判断する。

現行の公開方針は記事本文・画像・取得HTMLの配布を含まない。取得時の原文効果は非公開監査入力に留め、公開用には数値・対象・条件・継続ターン等を事実として構造化し、表示文を生成する。構造化不能な効果は needs_review とし、内容を推測せず個別Wikiへ誘導する。原文の効果文をそのまま公開する変更は今回決めない。構造化可能率は未検証で、試作時に評価する。

## ライブスキル検索

各ライブスキル行に mechanics[] を持たせ、値は link / plus / change / grow / refrain。MB版も独立してタグ付けし、通常版から継承しない。GrowUp・Grow は grow、Reflain・Refrain は refrain に正規化し、原表記と出典位置は監査側に保存する。大小文字を正規化し、そのスキルの効果欄に明示された機構のみ採る。解説文、他スキル、思い出アピールのLinkから付与しない。複数タグを許し、一般解説にある組合せ制限をカードデータの排他規則として固定しない。

UIではP/Sと panel_live / mb_live / possessed_live を区別する。複数タグをANDにした場合は同一スキル行が全タグを満たすときのみ一致とする。OR、URL共有、件数、空結果、各タグの根拠節を試験する。スキル名と構造化済みの効果・条件も検索対象にする。未収録カードは「タグなし」ではなく「詳細未収録」と示し、検索結果に収録範囲を表示する。
