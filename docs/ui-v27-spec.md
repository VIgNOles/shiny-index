## 表示と読み込み

基本データの確認後に基本検索を使える。詳細取得中の性能・育成特性URLは、条件を保持して待機表示し、基本情報だけの候補を性能検索結果と誤表示しない。失敗後も基本検索は利用できる。

詳細未収録・読み込み中・失敗を一覧に表示する。一覧は短い一致要約を残し、「一致した性能」で全一致項目の値・発動条件・確率・回数・解放段階を展開する。性能や育成特性で探したときは、詳細内でも目的の情報を基本情報より先に置く。閉じたカード詳細と一致理由は初回展開時に構築し、「さらに表示」は100件だけ追記して既存DOM・展開状態を維持する。

スマホでは人物・シリーズ・性能・育成特性を通常画面から使い、下部の「条件へ戻る」「結果を見る」で往復する。選択条件は折り畳める。全解除は折り畳みの外に残す。詳しい条件の編集は従来どおり下書きで、取消／適用／戻る／Escape／幅変更の扱いを維持する。

## 新しい検索条件

| URLキー | 対応範囲 |
|---|---|
| `effect_scope` | `base/link/plus/change/grow/refrain/memory_link/memory_charge`。同じ効果に明記された範囲 |
| `effect_unit` | `multiplier/percent/points`。倍率／％／ポイント |
| `effect_min` / `effect_max` | 選択単位の確定効果量の上下限、境界を含む。単位必須 |
| `unlock_star_max` | 0〜4。同じ一致スキルの明記された必要特訓がこの値以下 |
| `trait_idea` | Sカードのボーカル／ダンス／ビジュアル／アピール／トーク |
| `trait_inspiration` | SカードのVocal／Dance／Visual／メンタル。Vo.・Vo等を検索用に正規化 |
| `trait_music` | 歌唱力／表現力／安定感／団結力／集中力。同じSカードで他特性とAND |
| `card_id` | 1件の固定カードID。他の検索条件とはAND |

効果量は最大・範囲・式・Lv依存・人数依存・PERFECT別値など条件で変わる数値を含めない。発動確率を効果量へ転用しない。効果の種類・属性・範囲・量・対象・期間・キーワードは同じ効果、ランダム付与は同じ候補で判定する。必要特訓の不明を0凸と扱わない（現行データの明記0凸は0項目）。

「Link付きスキル」は従来どおりLink機能の所持条件であり、Link部分そのものの効果とは区別する。後者は範囲をLinkに指定する。

人物33名の確定読みを基礎検索へ追加。かな／カナ／半角と空白を正規化し、既存の空白区切りANDを維持する。未知の読みや誤字を推測しない。「用語と検索例」は必要時に開き、例の選択で条件を一式置き換える。

## 個別URL・共有・比較

カード名のリンクは `?card_id=<固定UUID>#results-heading`。名称の変更に依存せず対象1件を開き、詳細を展開する。未知・空・複数の個別IDは明示エラーと解除チップを表示する。

「検索条件のURLをコピー」は入力中の検索を反映してからURLをコピーする。移動用フラグメントを除く。クリップボードを使えない場合は、選択済みの読み取り専用URL欄を表示して手動コピーできる。検索入力・条件変更・履歴移動時はその欄のURLと通知を消去する。遅れて届いた古いコピー結果は表示しない。

「比較に追加」で同じページ内の2〜4枚を一時比較する。5枚目は選択不可。条件変更・履歴・詳細到着でも選択を維持し、適用中の条件で比較を更新する。未適用の下書きは反映しない。結果外の選択カードにはその旨を表示する。

比較表は基本情報・育成特性・一致した全スキルをカードごとの列に表示する。値・条件・確率・回数・必要特訓・イベント解放・Lv式と取得表を併記し、条件差を最大値1件で代表させない。性能条件なしでは全項目を展開できる。未収録・読込失敗・不明特訓と、旧形式の追加参考値を明示する。選択は再読込時に保存しない。所持登録・名前付き保存には広げない。
