## 操作と意味
既存の「効果の種類・対象・継続ターン以上」とスキルキーワードを使う。メンタル回復・自身のメンタル消費・即時の思い出ゲージ増加・リラックス・パッシブスキル強化・交換数UP・リフレインを追加。パッシブ発動率UPと回避率の継続効果も対象になる。即時回復・交換回数・リフレインの「何ターン前」を継続ターンへ混ぜない。

例：「継続するUP効果」「Dance」、キーワード「2ターン以前」で、同じDance効果に付いたPlus条件を検索できる。条件は区間先頭の括弧から完全に解析できる場合だけ導出し、別区間・通常効果・思い出の追加スロットへ漏らさない。AND/ORと人物・ユニットの意味は既存の検証済み条件型を再利用する。保存R01のLink節により、Link区間先頭の一意な人物略記は履歴条件として導出する（単独/列挙、AND）。汎用の参加条件パーサへ略記を渡して参加と混同しない。明示のライブ参加文言はそのまま参加条件として扱い、未知名・重複・曖昧な記載は未構造化として表示する。原文は公開しない。

変動要因（注目度・メンタル・回復回数・履歴など）、興味無視、必ず最初/最後にアピールは対応する効果へ付けて表示する。最大倍率を無条件値にしない。検索と一致強調は同じ判定関数を使い、キーワードに合わない通常効果を強調しない。
