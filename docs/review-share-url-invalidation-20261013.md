# 公開前修正：共有URL欄の無効化（2026-10-13）

対象はGit `3c79f81` のUI27。レビュー指摘を実物とブラウザーで確認し、修正前に新しい回帰試験が失敗することを保存した。手動コピー欄はコピー失敗時に表示するだけで、条件変更時にURL・通知を消していなかった。

## 変更

- 検索入力開始／入力／条件変更時に、手動欄を隠し、値とコピー通知を空にする。180msの入力待ちやIME確定を待たない。
- 適用された検索URLの変更も検出し、チップ解除・全解除・並べ替え・履歴・スマホ詳細条件の適用を含める。
- コピー操作ごとに世代を更新。古いClipboard APIの成功／拒否は、後から欄・通知・焦点を復活／上書きしない。
- 条件不変の詳細表示・比較選択・追加表示では、現在の検索URL欄を保持する。
- 新しい回帰試験を `npm run test:ui` へ登録。UI27・固定ID・検索仕様・データ形式は維持する。

スマホの長い比較表の指摘は今回保留とし、比較表の描画・一致項目の描画・HTML・CSSを変更しない。独立レビューでも修正境界を確認した。

## 検証と保存

- 修正前：入力イベント直後に旧URLと通知が残り、新試験が期待どおり失敗。
- 修正後の専用試験：1280／390／320幅の入力直後、select、チップ、全解除、並べ替え、戻る／進む、新URL再コピー、スマホ下書き取消／適用が成功。条件不変の操作も確認。
- 180ms待ちの前に古いClipboard結果を返すケース、コピー2回の逆順完了、IME入力で旧表示が復活しないことを確認。
- 既存共有・比較3幅、検索操作6幅、JS97、検索450セット（独立97）が成功。全108ファイルとソース一致、採用後のSHAも照合。公開用の変更はapp.mjsだけで、他107ファイル不変。
