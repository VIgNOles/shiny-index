## 283ステージと性能情報

現行のcards.jsonにはステータス、性能、スキル、283ステージ用の評価・効果値を収録していない。Wiki個別ページへのリンクとカードの基本索引だけを保持する。性能検索は、根拠・項目定義・更新方法を別途設計してから拡張する。

画面上部は「シリーズ・入手から探す」と呼び、プレコレ、キャスコレ、パラコレ、トワコレ、マイコレ、期間限定、恒常、その他の順にする。複数選択は同一軸でOR。URLは新しいbrowseキーで固定し、旧series_ids URLは従来どおり評価する。

## 詳細条件との使い分け

「シリーズ・企画」は誕生日、投票企画、エクスパンション等を含む完全な系列軸。「入手区分」はコレクションガシャ、イベント報酬、特典等を含む完全な取得方法の軸。上段の近道は発見の入口、詳細の2軸は正確な追加絞り込みとして残す。同じトワコレや期間限定が両方に現れるのは、前者が広い入口、後者が他条件とANDで組み合わせる詳細指定という役割の違いによる。URL・選択中チップには近道と詳細の別を明示する。近道内はOR、近道と詳細条件の間はAND。例: 近道「期間限定」+詳細「誕生日」は41件。異なる軸の矛盾で0件になる選択も可能で、選択中チップと全解除で原因を確認できる。

## 人物選択とCSV

「ユニット・アイドル」詳細を開いたら、各ユニットの全員チェックの下に所属アイドルを常時表示する。ユニット単位、一部選択、個別解除、旧人物URLのAND互換は維持する。

検索結果CSVボタンと全件CSVリンクを画面から外す。既存の不変データ版のCSVファイル直接URLは維持する仮実装で、ファイル自体の公開停止が必要かユーザーに確認中。JSON、Excel、版、出典への導線は維持する。
