初版は保存済み原本r19から派生変換した。続いてユーザーが回避時UPの属性2項目をVisualと確認したため、非公開原本コピーの手修正へ登録しr20を採用した。全1,419カード/24,025項目、固定ID、既存6手修正を保持し、手修正は計8件。基礎r7・全不変バンドルは不変。Wikiへの新しい通信は0。属性補正はデータ更新のためUI v18を維持する。

## 根拠と型

保存R01「スキル効果の解説」のskill_013（興味反転）、skill_020（興味限定）、melancholy、skill_011（回避時）、skill_015（ダメージ時）と各カードの原セルを照合する。R01 SHA31fc776620cf8afe25d60f2acc634d2bcdf9721972c4b7143054f026deedb913。全文を再配布せず、検証済みの型・対象・数値・期間を派生公開する。

- 興味反転と興味限定は独立したBoolean効果。通常の興味倍率や興味無視と混同せず、原文にない固定倍率を代入しない。
- 全観客の明記はその効果だけに付ける。先行する全観客アピールを隣の裸の興味反転へ伝播しない。
- メランコリーはpercent/メンタルとrecipient=self/rivals/all_unitsを保持。即時の自身メンタル消費や回復と別型。保存R01に従い、付与の翌ターンからアピールフェイズ開始時に現在メンタルに対する減少と表示する。
- 反応時UPはrate_upにtrigger=reaction_evaded/reaction_damage、trigger_turns（反応を待つ期間）、turns（付与後の継続）、uses（付与回数上限）を付ける。観客のリアクション回避成功・リアクションによるダメージが契機であり、単なる非被弾、自身メンタル消費、メランコリー減少を契機としない。
- 既存の継続ターンフィルターは付与後のturnsへ適用し、反応待ち期間を足したり代用しない。回避率/成功確率や必ず付与されるという保証を作らない。画面に待機期間・付与後期間・回数上限・契機を別々に表示し、キーワード検索で区別できる。
- 1つの反応時効果内にDa/Viの複合付与がある場合は各対象を分け、原文の回数上限をshared_uses=trueで共有と明記する。回数を対象ごとに加算したり、独立した即時UPとして抽出しない。保存R01の回数制限は付与したバフ数による消費であり、イベント回数と同一視しない。
- 未対応の反応時本文でも、その区間の末尾だけを通常UPとして誤抽出しない。属性が欠けた「回避時100%UP」「回避時120%UP」の2項目は周辺アピールから推測しない。P【ダイヤモンド・クラリティ】樋口円香の該当2項目についてユーザー回答「2つともVisualUPと理解してかまいません」を根拠とし、取得列を残して手修正へVisualを登録した。エージェントがゲーム画面を独立確認した情報とは区別する。以前解消した5パッシブ条件とは別の原文欠損で、今回の確認待ちは0。

## 検証・規模・互換

r19初版はUI17に対し126項目/127効果を追加した。ユーザー確認2項目のr20補正を含む最終版は128項目/129効果：興味反転36、興味限定15、メランコリー10、反応時UP68を追加し、既存VisualUP1効果を反応条件付きへ補完した。反応時効果は回避35/ダメージ34、計69（複合共有2を含む）。既存値は失わず、原文/coverage/全ID/既存6手修正を保持。r19初版との公開差分は補正対象2項目の追加効果・参考数値・manual_source_refだけで、他24,023項目は完全一致。保存済み全1,419候補をr20へ再適用しても原本全体が一致する。認識済み効果に結び付いた区間条件688構造化/未対応0、旧UI向けfallback57は維持。ライブ全項目のpartialは維持し、全複合効果の完成とはしない。

detail_schema1.0のoptional fieldを拡張する。新フィールド・対象・契機・共有上限の相手・型/範囲を厳密検証する。旧UI17は新型や反応triggerのラベルに未対応のため、切戻し時はUI17と既知の派生版d1-a0e7716b08316259を組にする。これは補正前のr19データへ戻す組で、今回の補正を含むr20原本と同じデータ状態ではない。r20原本と旧r19原本コピーの両方を保存し、新しい不変バンドルも削除せず保持する。UI17タグだけの旧ファイル集合をそのまま再公開して新しい版付きURLを消さない。

効果選択肢と表示を変更するためUI v18。今後データだけの更新ではv18を維持する。公開状態と検証実績はHANDOFF.mdとdocs/verification.mdを参照。
