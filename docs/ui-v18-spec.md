# UI v18：興味操作・メランコリー・反応時の付与

保存済み原本r19から派生変換する。全1,419カード/24,025項目、固定ID、6手修正、基礎r7、不変バンドルを保持する。新しい取得・Google原本への書込は不要。

## 根拠と型

保存R01「スキル効果の解説」のskill_013（興味反転）、skill_020（興味限定）、melancholy、skill_011（回避時）、skill_015（ダメージ時）と各カードの原セルを照合する。R01 SHA31fc776620cf8afe25d60f2acc634d2bcdf9721972c4b7143054f026deedb913。全文を再配布せず、検証済みの型・対象・数値・期間を派生公開する。

- 興味反転と興味限定は独立したBoolean効果。通常の興味倍率や興味無視と混同せず、原文にない固定倍率を代入しない。
- 全観客の明記はその効果だけに付ける。先行する全観客アピールを隣の裸の興味反転へ伝播しない。
- メランコリーはpercent/メンタルとrecipient=self/rivals/all_unitsを保持。即時の自身メンタル消費や回復と別型。保存R01に従い、付与の翌ターンからアピールフェイズ開始時に現在メンタルに対する減少と表示する。
- 反応時UPはrate_upにtrigger=reaction_evaded/reaction_damage、trigger_turns（反応を待つ期間）、turns（付与後の継続）、uses（付与回数上限）を付ける。観客のリアクション回避成功・リアクションによるダメージが契機であり、単なる非被弾、自身メンタル消費、メランコリー減少を契機としない。
- 既存の継続ターンフィルターは付与後のturnsへ適用し、反応待ち期間を足したり代用しない。回避率/成功確率や必ず付与されるという保証を作らない。画面に待機期間・付与後期間・回数上限・契機を別々に表示し、キーワード検索で区別できる。
- 1つの反応時効果内にDa/Viの複合付与がある場合は各対象を分け、原文の回数上限をshared_uses=trueで共有と明記する。回数を対象ごとに加算したり、独立した即時UPとして抽出しない。保存R01の回数制限は付与したバフ数による消費であり、イベント回数と同一視しない。
- 未対応の反応時本文でも、その区間の末尾だけを通常UPとして誤抽出しない。属性が欠けた「回避時100%UP」「回避時120%UP」の2項目は周辺アピールから推測せず保留。これは以前解消した5パッシブ条件とは別の原文欠損。

## 検証・規模・互換

UI17に対し126項目/127効果を追加。興味反転36、興味限定15、メランコリー10、反応時UP66を追加し、既存VisualUP1効果を反応条件付きへ補完した。反応時効果は回避33/ダメージ34、計67（複合共有2を含む）。既存値は失わず、非effect_details値・coverage・ID・手修正は全件一致。認識済み効果に結び付いた区間条件688構造化/未対応0、旧UI向けfallback57は維持。ライブ全項目のpartialは維持し、全複合効果の完成とはしない。

detail_schema1.0のoptional fieldを拡張する。新フィールド・対象・契機・共有上限の相手・型/範囲を厳密検証する。旧UI17は新型や反応triggerのラベルに未対応のため、切戻し時はUI17と既知の派生版d1-a0e7716b08316259を組にする。原本r19や非効果値/ID/手修正は同一のまま、新しい不変バンドルも削除せず保持する。UI17タグだけの旧ファイル集合をそのまま再公開して新しい版付きURLを消さない。

効果選択肢と表示を変更するためUI v18。今後データだけの更新ではv18を維持する。公開状態と検証実績はHANDOFF.mdとdocs/verification.mdを参照。
