# UI v23：強化アピールと人物別倍率UP

保存済みr20とR01の解説を使い、原本を変更せず派生データと検索表示を補完する。検索・表示を追加するためUI v23。既存UI22/bf612eと全不変URLを保存する。

## 意味と構造

- 属性強化は、そのアピールで指定属性のステータス効果を2倍として計算する。パッシブは対象外。アピール自体の倍率を2倍にしたり、2倍のUPを新規付与したりしない。
- 魅了強化は、そのアピールで魅了効果を1.5倍として計算する。期間を持つ新規の魅了付与とは区別する。
- 上記は既存appeal factのappeal_enhancement={target,factor,this_appeal_only}として付ける。原文の隣接括弧だけを対象にし、次のアピール・Link/Plus・思い出追加へ引き継がない。元の倍率/対象/期間を変えない。
- 人物別倍率UPはmetric=idol_appeal_bonus、targets=アピール倍率、unit=multiplier、value=加算する倍数、turns=明記期間、restrictions.idols=一意に照合した全対象人物。既存のアビリティ由来のアピール値%UPとは別の種類にする。
- 人物別倍率UPの最大値は明示されたGrow区間だけで認める。未知名・重複・単位欠落・期間欠落・条件括弧内の効果文は採用しない。
- R01 skill_012に従い、人物別倍率UPは思い出本体・[追加]効果・チャージに適用されないことをbonus_excludesで明示する。数値の最終計算は行わない。
- 既知の「メンタルが多い程」「注目度が高い程」表記を既存のscalingへ統一する。原文は保持する。

## 検索

「強化アピール（属性・魅了）」は既存appealの修飾があるものだけを選ぶ。「人物別アピール倍率UP」は確定付与される同じ効果内で人物名・継続期間・語句を照合する。ランダム候補は従来どおり明示的な候補検索に限定し、確定倍率UPへ混入させない。

属性・能力フィルターはその効果のtargetsに対して判定する。強化対象はキーワードと表示で確認できる。強化アピールは即時効果なので継続ターンを借りない。人物別倍率UPの継続期間は他のアピール/UPやランダム候補から借りない。
